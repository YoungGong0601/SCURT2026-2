# 02. 플레이어 디자인

> 2026-09-29, 상태: 확정 (구현 완료)
> 플레이어 **디자인 컨셉**의 단일 출처다. 정확한 픽셀은 `Art/Player/*.svg`, 구현 구조는 [ARCHITECTURE.md](../ARCHITECTURE.md)에 있다.

## 목표
WASD로 상하좌우 이동하는 캐릭터 하나. 이동 방향이 **눈에 보여야** 한다.
연구의 중심은 무한 맵이므로 플레이어는 최소한으로 만든다.

## 디자인 도구: SVG (Figma 대신)
| 비교 | Figma | SVG |
|---|---|---|
| 저장 위치 | Figma 클라우드 | 저장소 안 텍스트 파일 |
| Unity 반입 | 내보내기(export) 단계 필요 | PNG로 변환해 사용 |
| 변경 추적 | Figma 버전 기록 | 텍스트 diff |
| 단순 도형 제작 | 손으로 그림 | 좌표로 정확히 기술 |

흰 네모와 눈 수준의 캐릭터에는 SVG가 더 간편하다.

## 캐릭터 컨셉: "흰 네모"
- **몸통:** 흰색 정사각형, 얇은 어두운 외곽선(배경과 구분용), 바닥 쪽 옅은 그림자 한 줄
- **캐릭터성:** 검은 두 눈. **눈이 바라보는 방향 = 이동 방향**
- 멈추면 마지막 방향의 모습을 유지한다. 대각선으로 움직이면 좌우 모습이 우선한다.

| 방향 | 키 | 표현 |
|---|---|---|
| 아래 | S | 두 눈이 아래쪽으로 |
| 위 | W | 두 눈이 위쪽으로 |
| 왼쪽 | A | 두 눈이 왼쪽으로 |
| 오른쪽 | D | 두 눈이 오른쪽으로 |
